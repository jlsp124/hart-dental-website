# Asset provenance and rights boundary

## Used in the private preview

The following were retrieved from Hart Dental’s current public website and appear specific to the clinic:

- Hart Dental logo and mark source.
- Current team group photograph.
- Current dentist and staff portraits.
- Office exterior photograph.

They are used for a private, isolated replacement preview because they depict Hart Dental itself. This is not proof of production reuse rights. Before launch, Hart Dental must confirm ownership/licensing, consent for current staff portraits and permission to publish each image. Request the original files and a vector/source logo; replace compressed web copies where available.

## Intentionally excluded

- Vendor HTML, Drupal templates, CSS, JavaScript, icons and layout.
- Optio Publishing videos and patient-education content.
- Current map/API implementation.
- Treatment/stock imagery without licence evidence.
- Third-party organization marks or community photos without explicit approval.

`Old site mirror/` is excluded from Git and from the new repository history. The replacement design, CSS, TypeScript, page structure and rewritten copy were created independently.

## Before production

Record for every asset: owner, source file, date received, scope of licence/consent, expiry or removal requirement, and approved public use. Remove or replace anything Hart cannot affirm.
